Icon directions for Telexpense

The app already uses Lucide. These previews show four coherent icon languages against the current Mini App UI, rather than mixing unrelated icon sets.

Recommended: refined Lucide. It keeps the current package and data model intact, but uses a lighter 1.8px stroke and a smaller, more purposeful finance set.

1. Refined Lucide

Calm, clear outlines. Best fit for the app's existing soft-green, information-dense design.

Recommended. No package change

Implementation trade-offs

DirectionPackageFitDecision
Refined LucideAlready installed: lucide-reactConsistent outlined finance set, named tree-shakeable imports, ISC license.Recommended
Heroicons@heroicons/reactMIT license. 24px outline and solid variants make selected states more emphatic.Strong alternative
Hugeicons@hugeicons/react and @hugeicons/core-free-iconsMIT free set. Rounded style and broad coverage, with more bundle and dependency cost.Use only for a deliberate softer look
Radix Icons@radix-ui/react-iconsMIT license. Excellent small interface glyphs, but not enough finance/category coverage alone.Use alongside Lucide, if needed
