# Telexpense

Telexpense records personal finance activity through a Telegram bot and Mini App. This glossary names the financial concepts shared by those entry points.

## Transaction capture

**Concise capture**:
A transaction entry expressed as an amount and description, or an `/income` command. It may need the user to select a category, subcategory, or account before it becomes a transaction.
_Avoid_: quick entry, Telegram flow
